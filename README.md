# Loan Approval Analysis Dashboard

## Overview
This project presents an interactive Tableau dashboard for analyzing loan approval data. It helps identify trends in loan approvals based on applicant demographics, income, education, property area, and credit history.

## Key Performance Indicators (KPIs)
- Total Applications: 614
- Approved Loans: 422
- Rejected Loans: 192
- Approval Rate: 68.7%

## Dashboard Features
- Loan Status Analysis
- Education-wise Analysis
- Gender-wise Analysis
- Property Area Analysis
- Applicant Income Distribution
- Credit History Analysis

## Tools & Technologies
- Tableau
- Microsoft Excel

## Dataset
Loan approval dataset containing applicant and loan details.
